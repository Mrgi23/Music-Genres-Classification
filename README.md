# Music Genres Classification

## Description
The **Music Genres Classification** is a deep learning project that leverages convolutional neural networks (CNNs) for accurate and efficient classification of audio signals into musical genres. Designed for audio analysis and music information retrieval tasks, this system preprocesses audio samples and feeds them into a trained CNN model to predict one of ten music genres.

### Key Features
- **End-to-End Audio Classification** – From raw audio to genre prediction, all handled in a single pipeline.
- **Convolutional Neural Network (CNN)** – Utilizes a deep CNN architecture optimized for feature extraction from time-frequency representations.
- **Automatic Feature Extraction** – Learns relevant patterns from spectrograms and MFCCs, eliminating the need for manual feature engineering.
- **10-Class GTZAN Dataset** – Trained and evaluated on the widely-used GTZAN dataset containing samples from genres such as classical, jazz, rock, and hip-hop.
- **Multi-Language Prototyping** - Implemented in both **Python** and **C++** for flexible performance trade-offs.
- **Educational & Experimental Tool** – Suitable for learning, experimenting with neural network architectures, and understanding music classification challenges.
